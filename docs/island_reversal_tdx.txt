{==============================================================================
 孤岛反转选股公式（通达信 / TDX 条件选股）
 ==============================================================================
 形态定义：
   1. 向下跳空日 D1：当日最高价 < 前一日最低价（严格无重叠向下缺口）
   2. 向上跳空日 D2 = 今日：D1 后 1~N1 个交易日内，当日最低价 > 前一日最高价
   3. 孤岛不回补：D1 到 D2-1 之间所有交易日最高价都 < D1 前一日最低价
   4. 放量确认：D2 当日成交量 >= 前 N2 个交易日平均成交量的 R 倍

 使用方法：
   通达信 → 公式管理器 → 新建[条件选股] → 粘贴本公式 → 保存
   在[条件选股]中调用本公式即可筛选出今日触发孤岛反转的股票

 参数说明（可直接修改下方数值）：
   N1 = 30  向下跳空后多少日内出现向上跳空
   N2 = 5   量能均量计算周期
   R  = 2   量能倍数下限
==============================================================================}

N1 := 30;   {向下跳空后多少日内出现向上跳空}
N2 := 5;    {量能均量周期}
R  := 2;    {量能倍数下限}

{1. 今日向上跳空：今日最低价 > 昨日最高价}
T1 := L > REF(H, 1);

{2. 今日放量：今日成交量 >= 前N2日均量 * R}
{  说明：MA(V,N2) 含今日，REF(MA(V,N2),1) 为昨日的N2日均量 = 前N2日(不含今日)均量}
T2 := V >= R * REF(MA(V, N2), 1);

{3. 向下跳空条件（单日判定）：当日最高 < 昨日最低}
GAP_DOWN := H < REF(L, 1);

{4. 过去N1天内至少出现过一次向下跳空}
T3 := COUNT(GAP_DOWN, N1) >= 1;

{5. 最近一次向下跳空距今的周期数}
{  说明：今日若为向下跳空则N=0，今日为向上跳空则N>=1}
N := BARSLAST(GAP_DOWN);

{6. 向下跳空距今在 1~N1 个交易日内}
T4 := N >= 1 AND N <= N1;

{7. 孤岛不回补：向下跳空日到昨天的最高价最大值 < 向下跳空前一日的最低价}
{  REF(HHV(H,N),1) = 从昨日往回数N根K线(含昨日)的最高价最大值 = [向下跳空日..昨天]的最高价}
{  REF(L,N+1)      = 向下跳空前一日的最低价}
T5 := REF(HHV(H, N), 1) < REF(L, N + 1);

{========== 选股：所有条件同时成立 ==========}
XG: T1 AND T2 AND T3 AND T4 AND T5;


{==============================================================================
 附：宽松版（可选）—— 放宽量能要求，信号更多
 ==============================================================================
 将 T2 行替换为：
   T2 := V >= 1.5 * REF(MA(V, N2), 1);   {倍数降至1.5}

 附：严格版（可选）—— 要求缺口幅度显著
 ===============================================================================
 在 T5 后追加最小缺口幅度过滤（向下缺口>=1%，向上缺口>=1%）：
   T6 := (REF(L, 1) - H) / REF(L, 1) >= 0.01;          {当日(向下跳空)缺口幅度——仅当今日为向下跳空时有意义，此处不适用}
 注意：本公式站在向上跳空日(D2=今日)检测，向下跳空在N天前，其缺口幅度需用历史数据表达：
   GAP_DOWN_PCT := (REF(L, N+1) - REF(H, N)) / REF(L, N+1);   {向下跳空日的缺口幅度}
   GAP_UP_PCT   := (L - REF(H, 1)) / REF(H, 1);                {今日向上跳空缺口幅度}
   T6 := GAP_DOWN_PCT >= 0.01 AND GAP_UP_PCT >= 0.01;          {双向缺口均>=1%}
 最终选股行改为：
   XG: T1 AND T2 AND T3 AND T4 AND T5 AND T6;
==============================================================================}
